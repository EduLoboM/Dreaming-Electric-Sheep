# Detaching Fork on GitHub

This repository was originally initialized as a fork of `Neoteroi/BlackSheep`. To officially detach it on GitHub so it operates as an independent root repository with independent search, issue tracking, and packaging metrics:

## Step-by-Step Instructions

1. **Contact GitHub Support / Virtual Assistant**:
   - Go to [https://support.github.com/contact](https://support.github.com/contact) or open GitHub Support chat.
   - Choose topic: **Repositories** -> **Detach fork** (or request "Detach this fork").

2. **Specify Repository Details**:
   - Repository URL: `https://github.com/EduLoboM/Dreaming-Electric-Sheep`
   - Reason: "The project has diverged significantly into an independent Python 3.13+ serving stack (Dreaming Electric Sheep / `des`) with its own architecture, package name, release lifecycle, and roadmap."

3. **Verify Post-Detach Settings**:
   - Ensure **Issues** remain enabled under **Settings -> General -> Features -> Issues**.
   - Verify default branch is `main`.
   - Update Social Preview and About description if desired.
